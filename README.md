# 우리집 퀴즈

아이들을 위한 학습 퀴즈 웹앱입니다. (Vite + React, 백엔드 없음)

## 설치

```bash
npm install
```

## 실행 (개발 서버)

```bash
npm run dev
```

## 빌드 (배포용)

```bash
npm run build
```

## 빌드 결과 미리보기

```bash
npm run preview
```

## 현재 구현 상태

- 앱 시작 화면 (제목, 퀴즈 선택 버튼 2개)
  1. 초5 수학 퀴즈
  2. 초1 속담 퀴즈
- 반응형 레이아웃 (PC/태블릿)

퀴즈 문제 출제 및 채점 기능은 아직 구현되지 않았습니다.
